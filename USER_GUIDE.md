# Paralegal AI Assistant - Quick Start Guide

## Welcome to Paralegal AI Assistant!

This guide will help you get started with the standalone Windows executable.

## Installation

### Option 1: Installer (Recommended)

1. Double-click `Paralegal AI Assistant Setup {version}.exe`
2. Follow the installation wizard
3. Click "Install"
4. Wait for installation to complete
5. Click "Finish"
6. Launch the app from your desktop or Start menu

### Option 2: Portable

1. Download `Paralegal AI Assistant {version}.exe`
2. Place it anywhere on your computer
3. Double-click to run

## First Launch

When you first launch the application:

1. **Application Window Opens**: The main interface will appear
2. **Database Created**: A local database is created automatically
3. **Ready to Use**: You can start using all features immediately!

## Your Data Location

All your data is stored in:
```
C:\Users\{YourUsername}\AppData\Roaming\paralegal-ai-assistant
```

This includes:
- Notes and documents
- Settings and preferences
- Database files
- Application logs

## Basic Features

### Creating Notes
1. Click "New Note" button
2. Enter your note title
3. Add content
4. Click "Save"

### Using AI Assistant
1. Click "Ask AI" button
2. Type your question or request
3. Get intelligent assistance
4. Save helpful responses

### Managing Documents
1. Click "Documents" tab
2. Import files (if supported)
3. Organize with folders
4. Search and filter

### Settings
1. Click "Settings" (gear icon)
2. Customize preferences
3. Configure AI settings
4. Adjust appearance

## Keyboard Shortcuts

- `Ctrl+N` - New note
- `Ctrl+S` - Save
- `Ctrl+F` - Search
- `Ctrl+,` - Settings
- `Ctrl+W` - Close current tab
- `Ctrl+T` - New tab

## Troubleshooting

### Application Won't Start
1. Check if another instance is running
2. Restart your computer
3. Verify the file is not corrupted (redownload if needed)

### Lost Data
1. Check the data location mentioned above
2. Look for backup files in the same directory
3. Contact support if needed

### Performance Issues
1. Close other applications
2. Ensure you have 4GB+ RAM available
3. Check disk space (need at least 1GB free)

## Updating

To update to a newer version:

1. Download the new version
2. Close the current application
3. Install the new version
4. Your data will be preserved automatically

## Getting Help

- Check the full documentation included with the application
- Visit the help section in the app
- Contact support through the official channels

## Uninstalling

### If using the installer:
1. Go to Settings > Apps
2. Find "Paralegal AI Assistant"
3. Click "Uninstall"
4. Follow the prompts

### If using portable:
1. Delete the executable file
2. Optionally delete the data folder if you want to remove all data
